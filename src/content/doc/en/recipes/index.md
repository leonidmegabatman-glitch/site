Recipes are short scenarios for typical tasks. Each one answers "I want to do
X — how?", walks you through the steps, and links to the
[Interface](../interface/) section where every element is described in detail.

- [Dictate by voice](voice-input/) — speak a prompt instead of typing it.
- [Two agents in parallel](parallel-agents/) — give different tasks to two agents at once.
- [Keep the working tree untouched](isolated-run/) — an isolated run in a separate branch.
- [Run on a schedule](scheduled-runs/) — automatic task launches with cron.
