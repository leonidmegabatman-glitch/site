description: All Klavdiya keyboard shortcuts.
section: reference
order: 2
---

| Shortcut | Action | Where it works |
|---|---|---|
| `Ctrl+K` | Open manual search | Everywhere on the site |
| `Ctrl+T` | New project | Tab bar |
| `Ctrl+Shift+E` | Expand input bar to fullscreen | Chat |
| `Enter` | Send message | Chat |
| `Esc` | Close dialog / search | Everywhere |
| Middle mouse button | Close tab | Tab bar |

Application keys (not the site's) are gathered from `tabs:tooltip` and `promptInput` locales.
