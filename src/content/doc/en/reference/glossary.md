---

| Term | Meaning |
|---|---|
| **Agent** | An automated helper with a system prompt, launched with a task |
| **Worktree** | An isolated copy of a git repository for safe agent execution |
| **Checkpoint** | A session state snapshot you can return to |
| **MCP** | Model Context Protocol — a way to connect external tools to the agent |
| **Provider** | A service granting access to models (Anthropic, OpenRouter, etc.) |
| **Session** | One continuous dialogue with the agent within a project |
| **Skill** | An instruction file (SKILL.md) the agent applies by context |
| **Subagent** | A nested agent launched by the main session for parallel work |
| **Hook** | A command executed on an agent lifecycle event |
| **Gateway** | An intermediary server between Klavdiya and the model API |
