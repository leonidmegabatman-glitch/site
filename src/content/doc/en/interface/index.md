This section describes everything visible in Klavdiya's window: tabs, buttons,
checkboxes, fields, and panels. For each element it says where it is, what it is
for, and how to use it.

## How to read this section

Pages mirror the application's screens. Each one contains element cards: name and
type, "where to find it", "what it is for", "how to use it", a screenshot with a
highlight, and notes. Card anchors are stable: recipes and chats can link to them.

## What is documented

- [Settings](settings/) — all tabs: General, Permissions, Environment, Extensions,
  Hooks, Commands, Storage, Proxy, Voice.
