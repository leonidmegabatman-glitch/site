Klavdiya is a free desktop application for working with Claude Code: chat, agents,
a scheduler, voice input, extensions — all in one window instead of a terminal.
This site is its manual: for every interface element it says where it is,
**what it is for**, and how to use it.

The manual describes version **0.6.0**.

## Where to start

- [Interface](interface/) — a catalog of everything visible in the window: tabs,
  buttons, checkboxes, fields, and panels.
- [Settings → General](interface/settings/general/) — language, theme, chat history,
  and environment setup. The most visited page.
- [Screenshots needed](../../what-to-shoot/) — an internal page listing where the
  manual is still missing shots.

## How the manual is organized

The [Interface](interface/) section mirrors the application: pages repeat Klavdiya's
screens, and each page contains element cards. A card answers three questions: where
to find the element, what it is for, and how to use it — plus a screenshot with a
highlight once it has been taken.

Search opens with **Ctrl+K** from anywhere.
