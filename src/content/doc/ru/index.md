Клавдия — бесплатное десктопное приложение для работы с Claude Code: чат, агенты,
планировщик, голосовой ввод, расширения — всё в одном окне вместо терминала.
Этот сайт — её мануал: для каждого элемента интерфейса сказано, где он находится,
**зачем нужен** и как им пользоваться.

Мануал описывает версию **0.6.0**.

## С чего начать

- [Интерфейс](interface/) — каталог всего, что видно в окне: вкладки, кнопки,
  галочки, поля и панели.
- [Настройки → Общие](interface/settings/general/) — язык, тема, история чатов
  и установка окружения. Самая посещаемая страница.
- [Что нужно доснять](/site/ru/what-to-shoot/) — служебная страница: где мануалу
  пока не хватает снимков.

## Как устроен мануал

Раздел [«Интерфейс»](interface/) — это каталог-зеркало приложения: страницы
повторяют экраны Клавдии, а внутри каждой страницы — карточки элементов.
Карточка отвечает на три вопроса: где найти элемент, зачем он нужен и как им
пользоваться — плюс снимок с обводкой, если он уже сделан.

Поиск по мануалу открывается по **Ctrl+K** из любого места.
