Рецепты — это короткие сценарии решения типовых задач. Каждый отвечает на
вопрос «хочу сделать X — как?», ведёт по шагам и ссылается на раздел
[Интерфейс](../interface/), где каждый элемент описан подробно.

- [Диктовать голосом](voice-input/) — надиктовать запрос вместо печати.
- [Два агента параллельно](parallel-agents/) — поручить разные задачи двум агентам одновременно.
- [Агент не трогает рабочее дерево](isolated-run/) — изолированный прогон в отдельной ветке.
- [Запуск по расписанию](scheduled-runs/) — автоматический запуск задач по cron.
