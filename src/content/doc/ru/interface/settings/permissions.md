---
title: Разрешения
description: Режим разрешений, разрешающие и запрещающие правила для инструментов.
section: interface
order: 12
elements:
  - id: permission-mode
    title: Режим разрешений
    kind: select
    where: 'Настройки → Разрешения → первая секция'
    uiKey: settings:permissions.mode.title
    why: Определяет, как Клавдия запускает Claude Code при отправке сообщений. От режима зависит, будет ли агент спрашивать подтверждение на каждое действие или работать автономно.
    how:
      - Выберите один из пяти режимов в выпадающем списке.
      - Нажмите «Сохранить настройки».
    notes:
      - «Пропускать все проверки» — режим по умолчанию; правила ниже игнорируются.
      - «Режим плана» и «Ручное подтверждение» могут блокировать инструменты, но в чате нет запроса подтверждения — задача просто не выполнит действие.
  - id: allow-rules
    title: Разрешающие правила
    kind: panel
    where: 'Настройки → Разрешения → секция «Разрешающие правила»'
    uiKey: settings:permissions.allowLabel
    why: Список инструментов и команд, которые агент может выполнять без подтверждения. Позволяет сузить автономность до конкретных действий.
    how:
      - Нажмите «Добавить правило».
      - Введите имя инструмента или паттерн (поддерживается regex).
      - Нажмите «Сохранить настройки».
    notes:
      - Правила применяются только в режимах, отличных от «Пропускать все проверки».
  - id: deny-rules
    title: Запрещающие правила
    kind: panel
    where: 'Настройки → Разрешения → секция «Запрещающие правила»'
    uiKey: settings:permissions.denyLabel
    why: Список инструментов и команд, которые агент не может выполнять ни при каких условиях. Защита от опасных действий.
    how:
      - Нажмите «Добавить правило».
      - Введите имя инструмента или паттерн.
      - Нажмите «Сохранить настройки».
    notes:
      - Запрет имеет приоритет над разрешением.
  - id: add-rule
    title: Добавить правило
    kind: button
    where: 'Настройки → Разрешения → под списком правил'
    uiKey: settings:permissions.addRule
    why: Создаёт новую строку в списке разрешающих или запрещающих правил.
---

Вкладка «Разрешения» управляет тем, какие действия агент может выполнять
самостоятельно, а какие требуют подтверждения или заблокированы. Это основной
механизм безопасности Клавдии.
