Настройки открываются кнопкой с шестерёнкой в правом верхнем углу. Слева — вертикальный
список разделов, справа — содержимое выбранного. Вкладки идут в том же порядке, что
в самом приложении.

## Вкладки

- [Общие](general/) — язык, тема, история чатов, установка окружения и Claude.
- Разрешения — режим разрешений, разрешающие и запрещающие правила.
- Окружение — переменные окружения, скрипт API-ключа, сырые настройки.
- Расширения — плагины и скиллы: каталог, установленные, маркетплейсы.
- Хуки — команды на события жизненного цикла.
- Команды — свои слэш-команды.
- Хранилище — таблицы локальной базы данных.
- Прокси — прокси для запросов к Claude API.
- Голос — распознавание речи для диктовки.

Вкладки без ссылки ещё описываются.

## Общие правила

- Почти все изменения применяются только после кнопки «Сохранить настройки».
- Настройки хранятся в `~/.claude/settings.json` — их можно править руками,
  но проще через вкладки.
