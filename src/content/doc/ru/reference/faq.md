## Клавдия не находит Claude Code

Статус в верхней панели показывает «не найден». Решение:

1. Откройте Настройки → Общие → секция установки.
2. Нажмите «Установить Claude Code».
3. Если установка недоступна из-за региона, используйте запасной вариант через Node.js.

## Чат не отвечает

Проверьте:

- Статус Claude Code в верхней панели — должен быть «найден».
- Режим разрешений в Настройках → Разрешения.
- Прокси в Настройках → Прокси (если используете).

## Как сменить модель

В строке ввода чата есть выпадающий список моделей. Выбор действует
для текущего сообщения. Список моделей зависит от провайдера.

## Как работать голосом

1. Настройки → Голос → включите переключатель.
2. Выберите провайдера (локальный Whisper работает без интернета).
3. В чате появится кнопка микрофона.

## Настройки не применяются

Почти все изменения требуют нажатия «Сохранить настройки». Исключение —
правки в сыром JSON на вкладке Окружение.
