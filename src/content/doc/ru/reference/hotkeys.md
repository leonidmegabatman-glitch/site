---
title: Горячие клавиши
description: Все сочетания клавиш Клавдии.
section: reference
order: 2
---

| Сочетание | Действие | Где работает |
|---|---|---|
| `Ctrl+K` | Открыть поиск по мануалу | Везде на сайте |
| `Ctrl+T` | Новый проект | Панель вкладок |
| `Ctrl+Shift+E` | Развернуть строку ввода на весь экран | Чат |
| `Enter` | Отправить сообщение | Чат |
| `Esc` | Закрыть диалог / поиск | Везде |
| Средняя кнопка мыши | Закрыть вкладку | Панель вкладок |

Клавиши приложения (не сайта) собраны из локалей `tabs:tooltip` и `promptInput`.
