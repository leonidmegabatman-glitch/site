| Термин | Значение |
|---|---|
| **Агент** | Автоматизированный помощник с системным промптом, запускаемый с задачей |
| **Worktree** | Изолированная копия git-репозитория для безопасного прогона агента |
| **Контрольная точка** | Снимок состояния сессии, к которому можно вернуться |
| **MCP** | Model Context Protocol — способ подключить внешние инструменты к агенту |
| **Провайдер** | Сервис, предоставляющий доступ к моделям (Anthropic, OpenRouter и др.) |
| **Сессия** | Один непрерывный диалог с агентом в рамках проекта |
| **Скилл** | Файл-инструкция (SKILL.md), которую агент применяет по контексту |
| **Субагент** | Вложенный агент, запущенный основной сессией для параллельной работы |
| **Хук** | Команда, выполняемая при событии жизненного цикла агента |
| **Шлюз** | Промежуточный сервер между Клавдией и API моделей |
