# Сайт-мануал Клавдии

Статический сайт с полным описанием интерфейса Клавдии. Двуязычный: русский (основной) и английский.

## Запуск

    bun install
    bun run dev        # http://localhost:4321/site/

## Сборка и проверки

    bun run build      # статика в dist/
    bun run search     # индекс поиска (Pagefind) поверх dist/
    bun run verify     # проверки: карточки, ссылки, скриншоты
    bun run test       # юнит-тесты проверок
    bun run check      # типы

## Скриншоты

    bun run shots -- -Out src/assets/screenshots/interface/settings/general/panel.png

Скрипт находит окно Клавдии, поднимает его и снимает. Пока файла нет,
на сайте рисуется заглушка; страница «Что нужно доснять» перечисляет пробелы.

## Как добавить страницу

1. Создать `src/content/doc/ru/<путь>.md` с фронтматтером (см. соседние файлы).
2. Создать такой же файл в `src/content/doc/en/`.
3. Если у папки ещё нет `index.md` — создать его: каждому узлу дерева нужна страница.
